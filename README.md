# 💻 Projetos Responsivos - HTML e CSS (Desafios DevClub)

Este repositório reúne os desafios práticos de desenvolvimento web desenvolvidos durante os módulos do curso da <a href="https://www.devclub.com.br">**DevClub**</a>. O foco principal destes projetos é a aplicação de técnicas modernas de estruturação e estilização, garantindo que as páginas sejam totalmente responsivas e se adaptem perfeitamente a diferentes tamanhos de tela.
Para auxiliar nos testes e visualização, utilizei uma extensão do Google Chrome para simulação de múltiplas telas.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estruturação semântica de páginas web)
* **CSS3** (Estilização avançada, Flexbox e Media Queries)
* **Design Responsivo** (Adaptação fluida para múltiplos dispositivos)

---

## 📂 Estrutura do Repositório

O repositório está organizado em pastas separadas para cada desafio proposto:

* **`desafio 1/`** — Focado em estruturação inicial e estilização base.
* **`desafio 2/`** — Aplicação de conceitos de layout flexível e espaçamentos.
* **`desafio 3/`** — Implementação de responsividade avançada utilizando *Media Queries*.
